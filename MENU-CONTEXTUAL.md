# Registro del menú contextual

Mantener ManageBinaryFilesAction registrada en Projects/Actions y Projects/org-netbeans-modules-maven/Actions. No ocultarla según las carpetas Java: durante la carga del proyecto pueden no estar disponibles. Usar el proyecto del contexto; si no existe, permitir elegirlo. Conservar también el acceso desde View.

La versión se mantiene en 1.0 por solicitud del usuario. Después de recompilar, reinstalar el NBM para que NetBeans cargue los cambios; compilar no actualiza el plugin instalado.
